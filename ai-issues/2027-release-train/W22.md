## Pass 1 — Behavior and architecture

The existing guide starts E, T, A, N, I, M, S, O. Existing beginner listening
practice combines all letters, numbers and tiny groups. This optional path uses
the guide's order first, then the remaining alphabet letters in alphabetic order.
Seven cumulative sets contain 2, 4, 6, 8, 12, 18 and 26 letters. Membership is
visible and derives from one schema; prompts contain only those letters. No named
pedagogy, hidden adaptation, mastery threshold, certification or fluency claim.

The path is a disclosure on the existing audio-practice route. Selecting a set
updates the saved choice without interrupting the current round; Start selected
set explicitly starts ten prompts. Any set is available immediately. At completion,
the learner can repeat or choose the next set. Early finish does not add a completed
round. A complete round includes skips, explicitly disclosed as practice completion
rather than mastery. The existing solved/attempt/skipped scoring remains unchanged.

The same player, Morse encoding, canonical settings and full preset registry serve
ordinary and path practice. Changing a set stops playback. No prompt plays until
an explicit Play action. A static-pattern presentation offers the same targets and
grading without requiring sound or flashing. Flash Light stays in its compound
control, disabled with an explanation only in static mode; the saved flash preference
is restored when returning to listening. Sound/repeat/preset/timing settings persist
unchanged. Difficulty controls return to ordinary prompts; open-ended practice stays
available. Saved review handoffs remain separate from path rounds.

New registered key `mw_sound_first_progress_v1` stores only schema version, selected
set and seven bounded counts. It contains no learner answers. Counts cap at 9999
and display 9999+ at that bound. Schema rejects extra fields, invalid versions,
out-of-range sets/counts and oversized data. Malformed or inaccessible saved data
is not overwritten by ordinary actions; tab-only operation is disclosed. Explicit
path clear resets only this key. Site clear/storage events refresh saved progress.
Reload preserves choice/counts and opens ordinary practice, without autoplay or a
fabricated in-progress session. Existing keys are untouched.

## Pass 2 — Visual and accessible interaction

Home/audio rendered reference styles were inspected at W21: 24 browser/theme/width
observations, no overflow. This path reuses ToolButton and existing field tokens,
reading widths and flat section composition. No route, palette or shared CSS added.
Screenshot review covered mobile dark and desktop light layouts, with the full
26-letter set visible and wrapping cleanly. The static mode initially retained the
listening placeholder and feedback wording; those now describe reading a letter
pattern. The initial selector wrapped all options inside its label, producing an
overlong accessible name; a separate associated label corrects that. The path region
passes automated accessibility checks in mobile Chromium/WebKit light/dark; this
does not replace the screenshot and keyboard checks.
WebKit review also prompted using the existing `mw-tool-select-surface` class to
keep the selector fill stable on focus. Computed heading styles match the home/audio
font family, and the browser reports the heading face loaded.
