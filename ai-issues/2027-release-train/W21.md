## Pass 1 — Lifecycle audit and behavior

Ordinary practice already had ten prompts; sentence practice had eight, not ten.
Word trainer uses its selected deck length, audio/visual quizzes already have fixed
rounds, and typing has explicit duration presets. Listening practice was open-ended.
W21 preserves those existing task-specific counts and adds an optional ten-prompt
listening session alongside the existing open-ended path. The learning chooser's
listening start uses the short session; direct audio-practice entry stays open-ended.

Practice, sentence, listening, typing and the local review runner now offer an early
finish and truthful results. A checked/revealed current target is finished as solved
or skipped; untouched targets remain unfinished. Practice keeps answer-check accuracy;
sentence accuracy still includes skips in its denominator. Listening reports solved,
skipped and checked counts separately. No untouched target is credited as completed.
Review snapshots count solved/skipped/unfinished targets without deleting the queue.

Audit found that editing a correct listening answer returned feedback to idle and
allowed repeated credit for the same target. Per-prompt scoring now awards credit
once, retains correct/revealed status while editing and guards duplicate submission.
Replay does not affect scores. Next/Skip settles an unsolved listening target as
skipped. Finish stops the player, and reset/difficulty changes start a fresh session.
The ordinary practice advancement callback no longer performs other state changes
inside a state updater; explicit action guards also prevent duplicate correct credit.

Typing pauses on a hidden document and waits for explicit Resume. Its elapsed time
and results exclude the hidden interval. Early completion uses actual active time,
including in shared result cards, rather than the selected duration. Changing duration
from a paused run resets the run before using the new goal. Reload semantics are
disclosed: the current run starts fresh; saved settings/bests/review targets remain.
Free typing reports decoded text and pace, not a fabricated answer-accuracy score.
The deadline boundary is shared by timer ticks, explicit finish and visibility pause;
hiding between the deadline and the next tick completes the run rather than leaving
a zero-time paused session.

Untimed drills score explicit answers/advances only; no hidden-tab elapsed metric is
invented for them. The existing W12 audio/background ownership policy remains intact;
this package does not claim that all background audio is stopped. Finishing a listening
session explicitly stops its player. No automatic playback or return-time credit.

Next-step links depend only on the local queue: review saved targets when present,
otherwise offer the existing learning guide. Copy explicitly permits stopping and
returning later. No new streak pressure, remote state, telemetry or storage keys.

## Pass 2 — Visual, interaction and accessibility

Result headings receive keyboard focus. Typing uses the existing dialog focus helper
and a body portal, with background content inert while the modal is open. Results
use the existing opaque surface token, bounded viewport height and a compact mobile
grid. The initial functional matrix passed but screenshot review found the old
translucent result surface allowed page text to show through. That visual defect was
fixed before acceptance; no new palette or global CSS rule was added. Summary
paragraphs use the established reading-width constraint.
The nested share dialog also uses an opaque portal and returns focus to its trigger.
WebKit download behavior exposed a shared focus-helper defect: focus can return to
body, allowing the inert parent to consume Escape too. The helper now ignores keys
while its dialog is inert or the event is already handled. Navigation and display
settings consumers are included in regression coverage, including home and audio.
