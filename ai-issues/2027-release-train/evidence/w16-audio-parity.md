## Persistence boundaries

- W16 fixes first-entry migration: `/audio`, MP3, practice/quiz or the timing lab must find known legacy preferences before writing defaults. Canonical values always win. Existing explicit route adapters retain their previous legacy priority if two old namespaces coexist. Generic readers try translator then sound-generator legacy values; old values have no timestamps, so recency cannot be inferred. Old keys are preserved.
- Uploaded-book export profile: `morsewords:book-translator:preferences:v1`, sanitized by `sanitizeBookExportSettings`; Reader Quick Start is 18/12 WPM, 650 Hz, .75 volume, CW, 8/12 ms. It intentionally includes split/format/paragraph/sentence settings, rather than sharing all short-tool preferences.
- Public book and audiobook share `morsewords:book-runtime:settings:v1:<slug>:<contentVersion>:<contentHash>`; schema/content identity checked, initial-excerpt state cannot replace full-book selection. Saved section ordering/mode-specific default migration remains protected. Per-title context is intentional.
- Standalone video uses `morsewords:video-generator:preferences:v1`, defaults 18/12 WPM and CW registry defaults, all 13 presets. Its visual/format/source preferences are separate. It does not add attack/release controls to a workflow that did not expose them; canonical synthesis defaults remain used.
- `/practice` is a text recall task, not the audio practice/quiz engine. Its pools, scores, progress and answer privacy remain independent.
- Fixed reference samples, language samples and word trainer continue their existing focused options and storage scope. They use shared timing but do not advertise full equivalent synthesis controls. No automatic migration of those settings into short-tool preferences.

## Verification mapping

`audio-integration.spec.ts` reproduces both first-route legacy losses and translator-context fallback before the fix, then verifies all six rendered equivalent tools and canonical creative choice after navigation/reload. `interactive-settings-contract.spec.ts` checks ranges/defaults/Farnsworth limits, migrations, full rendered catalog and cross-route persistence. `audio-consolidation`, `audio-format-parity`, `audio-preset-registry`, `morse-timing`, `timing-lab`, `playback-ownership`, `mobile-audio-playback`, `export-job-recovery`, `preset-comparison` and `signal-inspection` cover actual engine boundaries, scheduling, exports and new interactions. Book startup/parity/segment advancement and video suites cover intentional task profiles. Exact cumulative run totals belong in W16/final review, not inferred from this source matrix. Physical Safari hardware remains outside this Windows browser harness.

W16 also cancels comparison synchronously in the disclosure summary activation task. Native `toggle` is queued and could otherwise leave playback active briefly after close; the existing toggle handler remains for programmatic close. The regression reads active nodes in the same task as closing and requires zero.

Cumulative harness corrections preserve production behavior: built-handler workers select production React before importing test modules; WebKit clipboard checks use an explicit API adapter because this runner cannot grant clipboard permissions; MP3 export tests open its existing advanced disclosure; Farnsworth assertions match the approved production page and still compare visible FAQ against JSON-LD; the video audio probe now supplies native AudioNode.disconnect so production cleanup can run. No production UI was edited to satisfy those stale fixtures.
