Shared feedback shows expected and submitted normalized values, their Morse patterns
when the task takes text, and marked changes with concise position explanations.
The comparator uses bounded edit alignment (240 characters, eight displayed groups)
and groups adjacent changes. It explains the existing grader; it does not grade with
a different whitespace rule. Long answers still receive the exercise's full check.

Practice, sentence practice, word trainer, audio practice, audio quiz and visual quiz
use the shared view. Multiple-attempt practice/sentence/visual tasks keep comparison
behind an explicit button after submission. Word and audio tasks already revealed
answers on check and retain that behavior. Existing manual reveal actions remain.
Snapshots preserve the submitted attempt while the next answer is edited, and clear
on skip, reset or advance. No comparison leaks before a submission. Free typing has
no expected target and receives no invented accuracy score or fabricated feedback.

## Pass 1 — Functional

sentence Morse retains word boundaries; audio/visual use plain-answer normalization;
ordinary practice also accepts pasted Morse in text answers. Each route supplies its
own already-normalized values, preserving these distinctions and existing algorithms.
Tested exact answers, wrong/missing/extra elements, formatting equivalence, bounded
long input, snapshot stability, retry, skip, keyboard comparison, live status and replay.
Fixed a Windows resolution collision between a similarly named `.ts` helper and
`.tsx` component by naming the pure helper `answerDifferences.ts`.

## Pass 2 — UX, visual, content

tablet and desktop observations. No new palette, card system or route. Initial
