## Pass 1 — Functional and storage audit

The existing word trainer kept weak words only in component memory. Its custom
source and best-streak keys were persistent; the other graded exercises stored
settings/bests but no target history. There is no old persisted weak-word queue to
migrate. W20 introduces `mw_learning_review_v1` without overwriting those keys.
Removing the new package leaves old scores, sources and settings usable, and the
versioned queue can remain dormant for a later restoration.

Practice, sentence practice, word trainer, listening practice, audio quiz and visual
quiz add the expected target after a wrong submission. They never save submitted
learner answers. The word trainer's explicit Mark weak action also adds a target.
One item per source/mode/target keeps repeat marks predictable; the count means
times marked, not a mastery score. The newest mark moves first, with at most 100
items and oldest-item eviction disclosed in the UI. Custom targets retain their
private flag even when later marked from another local round.

The queue is lazy-opened on the existing practice route and offered in the learning
chooser. It supports review, individual removal, confirmed clear-all and an empty
state. Review rounds snapshot their targets, so queue changes cannot silently jump
the active exercise. Word-trainer weak rounds also snapshot their targets and
private metadata; clearing word-trainer items leaves other exercise sources alone.

Sentence and word grading helpers were extracted without changing their policies.
Ordinary practice retains its own grader, including pasted-Morse text answers.
Sentence Morse retains explicit word boundaries and invalid-character checks;
word Morse retains its existing whitespace-insensitive check. Audio/visual retain
plain-answer normalization. Review delegates to these same rules.

Listening review hands one validated target through module memory to the existing
audio-practice route. The handoff expires after five minutes, consumes once and
survives StrictMode effect replay without reading browser state during SSR. It
places no target in URLs, history state or network requests. The existing player,
full preset registry, timing/settings and playback ownership remain authoritative.
The answer stays hidden until check/reveal, and playback still requires Play.
Next/reset/manual difficulty exits the saved-target task.

Malformed saved queues are preserved until an explicit clear. Denied/quota writes
leave a usable in-tab queue and explain that old saved items may return after reload.
The schema rejects extra fields, invalid modes/sources, HTML-like targets, duplicates,
out-of-range counts and oversized input. Its JSON bound allows escaped quotes at the
existing 4,000-character custom-source capacity. Native storage events and the site
clear-data event update mounted views. Word custom/best hydration now starts with
deterministic defaults and gates writes until restoration.

## Pass 2 — UX, visual and content

The queue uses shared buttons/input panels and the existing palette. Its list is
flat, with readable exercise labels, private markers and bounded target previews.
First screenshot review found an insufficiently visible light-mode textarea;
the answer field now uses the shared ToolPanel wrapper. No new visual token or
global CSS change was needed. Review does not make adaptive-learning claims or
automatically discard an item after one correct answer.
