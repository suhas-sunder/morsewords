## Pass 1 — Function and practice-surface audit

Visual practice and visual quiz now offer the exact same encoded target as a static
pattern. Reduced motion or the global Disable flash effects setting initially shows
that alternative. Explicit flashing remains available under reduced motion, matching
the existing global contract; global disable still blocks it. Static selection,
hidden tabs, changed prompts/timing, playback ownership changes and unmount stop
visual playback without auto-resume. Both visual routes now share one cancellation
hook and the existing canonical Morse event timing. No timing arithmetic changed.
Quiz targets, ten-question rounds, scoring and best-streak keys stay unchanged.
Best-streak initialization now waits for hydration before writing saved progress.

Audio practice and audio quiz already offer sound without flashing; W22 also offers
static recognition on the sound-first sets. Their exact existing strobe warning now
appears before the start controls whenever flashing is enabled, including lamp-only
flashing. Sound, Repeat and the compound Flash Light toggle/lamp keep their position
and behavior. No new warning colors, autoplay or route-specific engine settings.

Ordinary practice, sentence practice and typing have static tasks and no flashing.
Word trainer playback is audio-only. Review queue listening items now also offer
static recognition of the same target using the original answer rules. Copy states
that written recognition does not measure listening skill. Saved targets remain
until explicit removal; no new persistence key is needed.

## Pass 2 — Visual, keyboard and accessibility

Static output uses the shared dark signal palette and warm route composition.
Mobile, tablet and desktop screenshots cover both themes and Chromium/WebKit.
The review action row wraps with a real flex gap. An exercise heading supplies the
missing level before answer-comparison headings for screen-reader navigation. Keyboard checks cover static
selection, grading, full quiz completion and explicit flash/cancellation.

Initial full-main Axe checks exposed pre-existing nested complementary landmarks
and small faint text on warm surfaces. The visual routes opt into a placement-neutral
DarkNote div variant and a readable-support token using the existing text-soft color.
Slider/help/support metadata and the existing visible fallback caption get sufficient
contrast on those routes. Ad mounting, dimensions, requests, formats, fill detection
and page-wide fallback hiding remain untouched. Home keeps its existing appearance;
other DarkNote/SliderRow consumers retain defaults. Home/audio reference screenshots
are checked alongside affected routes.
